# Databricks and Azure MLOps Learning Project

## Objective

Build a repeatable machine learning pipeline and deploy a Streamlit
application through GitHub Actions.

## Development environment

All project code is written in Databricks and version-controlled
in the Learn-Data-Science GitHub repository.

## Learning milestones

1. Connect Databricks to GitHub.
2. Practise branches, commits and pull requests.
3. Store and read the dataset.
4. Validate data and prepare features.
5. Train and compare models with MLflow.
6. Register and select a model version.
7. Build a Streamlit application.
8. Add automated tests and deployment.
9. Make an update and practise rollback.
